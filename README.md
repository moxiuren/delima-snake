# DELIMa 贪吃蛇互动游戏 (Permainan Ular HTML5)

单文件零依赖 HTML5 Canvas 贪吃蛇游戏，专为嵌入 DELIMa 3.0 Ruang Ilmu 互动卡片及多端直玩而设计（参考 `kevo099/snake-game` MIT 单文件架构思路自研扩展）。

## 特性
- 单文件离线可运行（`index.html`），零构建步骤
- 键盘（方向键 / WASD / 空格暂停 / R 重开）、触屏划动、屏幕 D-Pad 全适配
- 中英 / 马来文（BM）一键切换
- 3 档速度（轻松 / 经典 / 极速）+ 穿墙模式开关 + Web Audio API 合成音效
- 紧凑自适应布局，完美贴合 DELIMa Ruang Ilmu `<iframe>` 卡片尺寸
